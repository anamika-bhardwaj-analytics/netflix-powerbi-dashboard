# Netflix Content Analysis Dashboard (Power BI)

## 📊 Overview
This project presents an interactive Power BI dashboard analyzing Netflix content to uncover trends in movies and TV shows across genres, release years, ratings, and global distribution.

## 🎯 Objective
To explore Netflix's content library and identify patterns in content type, genre popularity, release trends, and geographical distribution.

## 🚀 Key Insights
- Total Titles: 8,796  
- Total Movies: 6,124 (69.6%)  
- Total TV Shows: 2,674 (30.4%)  
- Total Genres: 42  
- Total Countries Represented: 124  
- Most Common Ratings: TV-MA (~3.2K titles), TV-14 (~2.1K titles)  
- Top Genres: International Movies (~3.5K), Dramas (~3.2K), Comedies (~2.0K)  
- Content Growth Trend: Rapid increase after 2015, peaking around 2019–2020 (~1.1K titles/year)  
- Global Distribution: Highest content concentration in North America, Europe, and India  

## 📈 Features
- KPI cards for total titles, movies, TV shows, genres, and countries  
- Ratings distribution analysis  
- Movies vs TV Shows comparison  
- Country-wise content distribution (map visualization)  
- Year-wise content release trends  
- Genre-based content analysis  
- Interactive filters (Type, Release Year)
